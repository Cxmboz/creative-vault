Context for any AI agent picking up this project. Read `AGENTS.md` at the vault root first.

## 1. Owner and goal

- Owner: Cxmbos (GitHub: Cxmboz). Hobbyist building Roblox combat animations; **main interest
  is animation, not modeling**. Willing to learn Blender, but does not want manual sculpting
  required for every weapon. Wants agents to take initiative and not re-ask about steps
  already done; ask only when input is genuinely needed.
- Goal: an **arsenal of distinct swords**, each with a matching scabbard, built for Roblox
  and animated in Blender. Each weapon must feel deliberately designed: its own identity,
  restrained, historically grounded where it borrows from a tradition. Accuracy over speed.
  Avoid the generic AI-fantasy look (random gems, glow, spikes, ornament everywhere).
- Long term the vault should support other game work too (environments, props, animation,
  scripting).

## 4. What has been done

### Animation groundwork (earlier sessions)
- Extracted and curated reference frames: 396 Ultra Instinct Goku frames, 17 Dragon Ball
  FighterZ frames (Gogeta SS4 vs Blue), Sae (Blue Lock) air awakening frames.
- Roblox Studio weapon rig: Katana and Sheathe models, each welded internally to a root part
  (`Handle`, `Scabbard`) with RigEdit; Motor6D `KatanaHold` (Right Arm → Handle) and a
  Motor6D (Left Arm → Scabbard). Planned a one-handed carry, then a draw inspired by Rimuru's
  draw (*That Time I Got Reincarnated as a Slime*): sheathed sword raised horizontally across the chest, other hand draws.
  Owner then moved to **animating in Blender instead of Eclipse** (prefers Blender).
- Imported the Roblox katana and sheath as OBJ into the Blender R6 rig scene (no textures;
  scale fix advised). Parenting to rig bones was in progress.

### First sword model: jian (Nov 1)
- Built procedurally with bpy 5.2.2 from the owner's concept (ornate straight jian, chevron
  blade, disc guard, dark scabbard with silver fittings and tassels). About 1,900 triangles for the sword and
  1,500 for the scabbard, one 1024 texture atlas each (color/metal/rough), FBX exported with Roblox settings.
- Retrospective: proportions right; surface detail too generic (redrawn ornament instead of
  the concept's); an invented beast-face pommel was a mistake (the owner corrected this: it was not in the concept).

### Arsenal design document (Nov 8)
- **Capability tiers**: Tier 1 (reliable by script): silhouettes and proportions from a side-view reference, blades, turned and
  extruded fittings, fitted scabbards, cords and tassels, UV atlases, Roblox export, and **ornament
  transferred from a reference into a baked normal map** (tested: a 410k-triangle relief baked onto 2 triangles).
  Tier 2 (to test per prototype): pierced guards, real-geometry grip wrap, organic forms in the round.
  Tier 3: detail the reference doesn't show (invented and flagged), effects (glow), fine sculpting, in-Roblox testing.
- **Technical standards**: 1 Blender unit = 1 stud, unit system None; sword origin at grip
  center, blade along +Z, width along X; scabbard origin at its mouth; a recorded "sheathed offset";
  rig prop bones `Prop_Weapon` (right arm) and `Prop_Scabbard` (left arm, switchable to hip), *not yet added to
  the rig*; Roblox root parts always named `Handle` / `Scabbard`; IDs J01/C01/E01/O01; budgets up to 4k
  triangles each (8k for signature weapons); FBX with "FBX Units Scale".
- **Prototype plan**: three weapons built to final quality to validate the workflow:
  J01 (Japanese, concept needed), C01 (rebuild of the jian), E01 (European, concept
  needed). Seven gates: silhouette within 2%, identity checklist, scabbard fit, materials, Roblox import, rig swap test, owner sign-off.

## 5. Design direction so far

- **Grounded first**; futuristic designs are a separate, parked track.
- Ideas on the table (none decided):
  - a **colorway system** (same mesh, swapped textures, for Roblox rarity tiers);
  - **one motif placed once** per scabbard;
  - a **three-material palette** with the cord as the accent color;
  - **ornament through texture** (fish-roe dot ground, stone-texture lacquer, sharkskin, wood grain);
  - **cohesion by construction**: the sword and scabbard share a wrap or material;
  - a **silhouette-first** process, with a strip of 8–12 variations per weapon;
  - a **twin swords in one scabbard** weapon class;
  - the E01 signature could be a **side ring** on the cross.
- Each reference note labels its elements Historical / Artistic / Process.

## 6. Rules to follow

- Originality: principles over pictures; at least 3 references per design including a historical one;
  record the lineage of each decision; check the cliché list; ornament only where the tradition puts it;
  trace only CC0 or public-domain material.
- Licensing: CC0 or public domain is free to use; CC BY needs credit; NC and ND are reference only;
  concept art is inspiration only. Skip works DeviantArt labels AI-generated. Honor creators' stated terms.
- Notes written by an agent use `verified: false`. Run `python scripts/build_index.py` after edits.

## 7. Technical gotchas

- Met API: search at `/public/collection/v1.1/search`, object records at `/v1/objects/{id}`.
- Cleveland API rejects Python's default user agent; use curl or set a user agent.
- Pinterest search needs a login (an agent may not sign in for the owner); individual pins open without one.
- The PC's Linux shell cannot delete files by default (this breaks git operations there) and has no GitHub
  credentials. Push from a cloud clone, then the owner pulls (Obsidian pulls on startup).
- bpy 5.2.2 (pip) runs headless for building models and Cycles renders.
