# Owner attachment - Katana colorway set

Inspiration only. No image is stored here; open the source link.

Five colorways of one katana design, plus two close-ups. The owner shared it; its original listing is not yet identified.

## What caught our attention
One shape becomes five weapons through color alone: brown, navy, black, white and crimson lacquer. The fittings switch between gold and black to suit each lacquer, and the cord matches each colorway. A thin flowing line motif starts on the scabbard fitting and continues across the grip, tying sword and scabbard together.

## Elements
| Element | Origin | How we could use it |
| --- | --- | --- |
| Colorway system (same shape, swapped lacquer, metal and cord) | Process | Roblox colorways or rarity tiers: same mesh, swapped texture set |
| Fitting metal chosen to suit the lacquer (gold or black) | Historical | Colorway rule |
| Line motif running from scabbard to grip | Artistic | Cohesion device; keep it to one thin line |
| Lacquered, patterned grip instead of a cord wrap | Artistic (uncommon historically) | A distinct option for one weapon, not a default |
| Ornate flame-shaped blade collar extending onto the blade | Artistic | Probably too much for J01; a candidate for the futuristic track |
