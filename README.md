# Creative Vault

A curated knowledge and reference library for game creation: weapons first, then
environments, props, animation, scripting and anything else we build for Roblox.

It is three things at once:

- an **Obsidian vault** you browse and edit (open this folder in Obsidian),
- a **Git repository** that keeps version history and lets AI agents read it,
- an **index** of a separate asset library (`../Creative Assets`), which is never committed.

## Start here

Open [[00 Home]] in Obsidian. Rules for AI agents are in `AGENTS.md`.

## Folders

| Folder | Holds |
| --- | --- |
| `Knowledge/` | Knowledge cards: traditions, parts, materials, techniques |
| `References/` | One note per external reference (museum object, material, doc page) |
| `Assets/` | One note per file in the asset library: where it is, its license |
| `Projects/` | Project notes and specs, e.g. the sword arsenal |
| `Boards/` | Obsidian Canvas boards |
| `Attachments/` | Small images only, CC0 or public domain |
| `_templates/` | Note templates (Obsidian Templates plugin) |
| `_system/` | Schema, license policy, originality rules, tags |
| `scripts/` | `build_index.py` (makes `index.json`), `check_links.py` |
